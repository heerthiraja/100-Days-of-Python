## 🎮 About the Game

This is a classic two-player Ping Pong game where each player controls a paddle to hit the ball back and forth. The goal is to prevent the ball from passing your side of the screen. The game is built using Python and the Pygame library, making it lightweight and easy to run on any system.

## 🚀 How to Run the Game

### Prerequisites
1. **Python**: Make sure you have Python installed. Download it from [python.org](https://www.python.org/).
2. **Pygame**: Install the Pygame library using pip:
   ```bash
   pip install pygame
   ```

### Steps to Run
1. Clone this repository or download the `ping_pong.py` file.
2. Open a terminal or command prompt and navigate to the project directory.
3. Run the game using the following command:
   ```bash
   python ping_pong.py
   ```
4. Enjoy the game! 🎉

---

## 🕹️ Controls

- **Left Paddle**:
  - `W` key: Move up.
  - `S` key: Move down.
- **Right Paddle**:
  - `UP` arrow key: Move up.
  - `DOWN` arrow key: Move down.
